# Persona

UI for live ride prices on one route.

The first screen asks for a pickup and a dropoff, then shows a fare next to a map. Arun Singh built that fare shell, including the Google API integration.

**Live:** https://persona-frontend-six.vercel.app

Fares come from the API in [persona_backend](https://github.com/LifeAyush/persona_backend).

**Repo:** https://github.com/LifeAyush/persona_frontend

## How to run

Install dependencies and start the Vite dev server:

```sh
npm install
npm run dev
```

`npm run build` writes a production build. `npm run preview` serves that build locally.
